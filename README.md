# Управление кулинарными рецептами (Recipe Management System)

Проект представляет собой систему для управления кулинарными рецептами, расчета ингредиентов при масштабировании порций и формирования списков покупок.

## Функциональность
- Создание ингредиентов с проверкой корректности данных.
- Создание рецептов и добавление в них ингредиентов (с автоматическим суммированием одинаковых позиций).
- Масштабирование рецептов в зависимости от количества порций.
- Создание диетических рецептов с указанием типа диеты.
- Формирование и объединение списков покупок из нескольких рецептов.

## Использование

### Запуск тестов
Для проверки работоспособности системы используются автоматизированные тесты на базе `pytest`.
Запустить их можно командой:
```bash
python -m pytest
```

### Пример использования в коде
```python
from src.recipes import Ingredient, Recipe, ShoppingList

# Создание ингредиентов
sugar = Ingredient("Сахар", 100, "г")
tea = Ingredient("Чай", 5, "г")

# Создание рецепта
recipe = Recipe("Чай с сахаром", [sugar, tea])

# Формирование списка покупок на 3 порции
sl = ShoppingList()
sl.add_recipe(recipe, 3)

# Вывод списка
for item in sl.get_list():
    print(item)
```
